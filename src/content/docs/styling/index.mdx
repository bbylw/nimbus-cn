脚手架写入的每个文件都由你掌管。先了解其运作方式，再选择要修改的部分。[组件目录](/components/)列出了所有可添加的组件。

- [定制的工作方式](/styling/how-customization-works/)：哪些文件归你、哪些属于框架，以及如何接收更新。
- [添加组件与功能](/styling/add-components/)：用 `nimbus-docs add` 安装组件或功能。
- [品牌](/styling/branding/)：Logo、名称、favicon 和颜色。
- [主题与令牌](/styling/theme-and-tokens/)：颜色、字体和间距背后的设计令牌。
- [布局](/styling/layouts/)：页面外壳，以及关闭某些列。
- [自定义组件](/styling/custom-components/)：编写自己的组件并在 MDX 中使用。
- [包 API](/styling/package-api/)：路由和布局所调用的辅助函数。
