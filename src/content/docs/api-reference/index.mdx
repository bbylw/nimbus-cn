Nimbus 根据规格文档生成 API 参考页面：每个操作、标签和 webhook 各一页，并带有搜索、Markdown 版本和 `llms.txt` 条目。目前支持读取 OpenAPI 3.x。

- [引用 API 页面](/api-reference/citations/)：在正文中用坐标链接到某个操作。
- [API 版本](/api-reference/versions/)：为同一个 API 提供多个版本，并显示版本选择器。
- [大型 API](/api-reference/large-apis/)：让大型规格的页面更小、构建更快。
- [OpenAPI](/api-reference/openapi/setup/)：从 OpenAPI 文档添加参考页面。
