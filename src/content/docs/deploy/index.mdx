- [部署到 Cloudflare](/deploy/cloudflare/)：默认方式；脚手架会自动配置。
- [部署到其他主机](/deploy/other-hosts/)：任意静态托管，或 Netlify、Node、Vercel 上的服务器。
- [部署到 GitHub Pages](/deploy/other-hosts/#github-pages)：本站采用的静态托管方式，配合自定义域名。
- [在路径下提供服务](/deploy/base-path/)：发布到 `example.com/docs/`。
