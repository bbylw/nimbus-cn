Nimbus 的组件既是页面构件，也是可以修改的源码。内置组件已经注册好，可以直接写进 `.mdx`；其余组件先用 CLI 安装，再按需注册。

| [`Aside`](/components/aside/) | `note`、`tip`、`caution`、`danger` 提示框 | 默认可用 |
| [`Badge`](/components/badge/) | 状态或分类小标签 | `nimbus-docs add badge` |
| [`Banner`](/components/banner/) | 站点公告条，可关闭并记住选择 | `nimbus-docs add banner` |
| [`Breadcrumbs`](/components/breadcrumbs/) | 指向当前页面的层级路径 | `nimbus-docs add breadcrumbs` |
| [`Button`](/components/button/) | 操作按钮，含变体、尺寸与形状 | `nimbus-docs add button` |
| [`Card`](/components/card/) | 带图标、标题与内容的卡片 | 默认可用 |
| [`CardGrid`](/components/card-grid/) | 卡片的自适应网格 | 默认可用 |
| [`Code`](/components/code/) | 从字符串渲染语法高亮代码块 | `nimbus-docs add code` |

| [`Pagination`](/components/pagination/) | 上一页 / 下一页 | `nimbus-docs add pagination` |

`Steps`、`Tabs`、`PackageManagers`、`Render` 等组件也已默认注册，可直接使用。

## 安装

```bash
nimbus-docs add accordion
```

命令会把组件源码写入 `src/components/ui/<slug>/`，并补齐注册表依赖。安装后的组件和其他源码一样，可以直接修改外观与行为。

## 注册

组件只有在 `src/components.ts` 中列出后，才能在任意 `.mdx` 里免导入使用：

```ts title="src/components.ts"
import { Badge } from "./components/ui/badge";

export const components = {
  Badge,
};
```

也可以只在单个文件顶部导入。未注册、也未导入的 PascalCase 标签会让构建失败，详见 [Markdown 与 MDX](/writing/markdown-and-mdx/)。
