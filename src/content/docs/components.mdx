每个 `.mdx` 文件都可以直接使用这些组件，无需导入。它们都是 `src/components/ui/` 里的文件，因此外观和行为都可以修改。

</Aside>

<Aside type="caution" title="部署之前">
  把 `astro.config.ts` 里的 `site` 改成你的生产环境 URL。
</Aside>

```mdx
<Aside type="note">

<Aside type="caution" title="部署之前">
```

| 属性 | 取值 |
|---|---|
| `type` | `note`（默认）、`tip`、`caution` 或 `danger` |
| `title` | 内容上方的标题，默认为类型名称。 |
| `icon` | 任意 `ph:` 图标名，用于替换类型自带的图标。 |

需要带格式的标题时，可以用插槽传入：`<Fragment slot="title">使用 <code>env</code></Fragment>`。

## Tabs

把同一内容的不同版本展示成标签页。给一组标签页设置 `syncKey` 后，读者的选择会同步到所有使用同一 key 的标签组。

<Tabs syncKey="os">
  <TabItem label="macOS">
    按 <kbd>⌘</kbd> <kbd>K</kbd> 搜索。
  </TabItem>
  <TabItem label="Windows">
    按 <kbd>Ctrl</kbd> <kbd>K</kbd> 搜索。
  </TabItem>
</Tabs>

```mdx
<Tabs syncKey="os">
  <TabItem label="macOS">
    按 <kbd>⌘</kbd> <kbd>K</kbd> 搜索。
  </TabItem>
  <TabItem label="Windows">
    按 <kbd>Ctrl</kbd> <kbd>K</kbd> 搜索。
  </TabItem>
</Tabs>
```

| 属性 | 取值 |
|---|---|
| `Tabs` 上的 `syncKey` | 相同 key 的标签组会一起切换，并记住选择。 |
| `TabItem` 上的 `label` | 标签名称，必填。 |

## 调整任意局部样式

每个组件的每个部件都带有 `data-slot` 属性，因此可以直接在 `src/styles/globals.css` 中修改某个局部，而不用改动组件本身。

```css title="src/styles/globals.css"
[data-slot="card-title"] {
  letter-spacing: -0.01em;
}
```

圆角由同一个文件中的两个变量控制：`--nb-radius` 用于卡片、提示框、代码块和按钮，`--nb-radius-sm` 用于它们内部的小元素。修改它们就能统一调整整个站点的圆角。
