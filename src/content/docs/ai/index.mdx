每个 Nimbus 站点都会为每个页面发布 Markdown 版本，以及一份 `llms.txt` 索引。以下页面说明它还能提供哪些内容，以及如何改变它发布的内容。

- [面向智能体的文档](/ai/docs-for-agents/)：智能体能从站点读取的全部内容，以及它如何找到这些内容。
- [Markdown 与 llms.txt](/ai/publish-markdown/)：Markdown 版本与索引，以及它们如何生成。
- [覆盖生成的 Markdown](/ai/override-markdown/)：修改某个页面的 Markdown、某个索引或分享卡片。
- [在页面 URL 上提供 Markdown](/ai/markdown-negotiation/)：在页面自身的 URL 上响应 `Accept: text/markdown`。
- [智能体发现](/ai/agent-discovery/)：智能体用来找到站点的文件与响应头。
- [远程 MCP 服务器](/ai/remote-mcp/)：让智能体通过 MCP 服务器读取文档。
- [发布 Agent Skills](/ai/agent-skills/)：发布智能体可以从站点安装的技能。
- [让浏览器智能体搜索文档](/ai/webmcp/)：在每个页面上提供 WebMCP 搜索工具。
