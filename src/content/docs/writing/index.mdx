按你要写的内容选择对应页面。需要现成的标签页、步骤和卡片时，见[组件目录](/components/)。

- [页面与路由](/writing/pages-and-routing/)：页面文件放在哪里，以及它对应的 URL 和侧边栏条目。
- [Markdown 与 MDX](/writing/markdown-and-mdx/)：页面里可以写什么，以及如何使用组件。
- [代码块](/writing/code-blocks/)：高亮、标题、行标记和包管理器标签页。
- [可复用片段](/writing/reusable-snippets/)：写一次内容，在多处页面中引用。
- [图表与交互内容](/writing/interactive-content/)：读者可以探索的交互式图表。
- [内容检查](/writing/linting/)：在发布前发现写作问题。
